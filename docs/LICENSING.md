# Licencjonowanie i pochodzenie materiałów

Projekt rozdziela analizę zachowania od kopiowania implementacji Java.

Kopie JAR-ów w testdata/okapi-filters-java/ są materiałem referencyjnym do badań i testów. Przed jakąkolwiek redystrybucją wygenerowanego kodu, danych lub artefaktów pochodzących z Okapi należy osobno ustalić warunki licencyjne.

Nie zakładamy automatycznie, że analiza JAR-a daje prawo do redystrybucji jego implementacji lub mechanicznie przetłumaczonego kodu.
